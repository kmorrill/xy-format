# Factory preset capture batches

These 18 device-authored projects contain the 142 OP-XY factory presets not
already covered by the clean default project or the separate Strings capture
batch. Assignments are defined by
`docs/workflows/factory_preset_capture_checklist_1.1.21.md`.

All assigned tracks were validated with:

- exactly one pattern;
- zero sequencer notes;
- the expected device-authored `category/preset` identity;
- a complete decoded track structure suitable for sound-state donor copying.

The device corrected one transcription error in the original name list:
`lead/azimuth` is the stored factory identity, not `lead/azimith`.

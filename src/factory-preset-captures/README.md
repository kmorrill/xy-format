# Factory preset sound-state captures

These are pristine OP-XY projects saved after loading shipping factory
presets on the assigned tracks. They provide the device-authored track state needed to reproduce that
sound safely when authoring a new `.xy` project.

Captures are grouped by firmware and factory category. Each category README
records the source track and validation constraints for that batch.

The firmware 1.1.21 `batches/` directory contains `fp01.xy` through
`fp18.xy`, covering the 142 factory presets not already supplied by the clean
baseline or the earlier Strings capture batch.

The captures contain project settings and references to factory samples on the
device. They do not bundle the factory sample audio.
